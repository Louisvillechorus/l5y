# L5Y — SHOT LIST & ASSET NAMING

*Every photo/video/audio the show needs, what to shoot, and the exact filename to upload.*

## How to name and upload

- **Naming rule:** Name every file by its asset code, then the cast suffix: -ml (Maegan & Landon) or -ac (Andrew & Charlie). Assets marked SHARED need no suffix — one file serves both casts.
- **Examples:** `M1-ml.jpg`, `M1-ac.jpg`, `M12.jpg`, `V2-ml.mp4`, `V2-ac.mp4`, `A1-ml.m4a`
- **Photos:** JPG (convert HEIC). Long side at least 1600 px. Keep each file under 8 MB so it travels through the Drive connector.
- **Video:** MP4 (H.264), 1920×1080, landscape. Videos exceed the Drive transfer limit — upload V2 to the GitHub repo (Add file → Upload files, into assets/) or hand it to the show laptop; tell me which.
- **Audio:** M4A or MP3, mono is fine.
- **Where:** One Drive folder, flat, e.g. “L5Y Assets” — tell me when it's there. Missing files are fine: a code that has no file keeps its placeholder, so partial uploads never break the show.
