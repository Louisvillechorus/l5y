*Every photo/video/audio the show needs, what to shoot, and the exact filename to upload.*

## How to name and upload

- **Naming rule:** Every filename says WHERE it plays, WHAT it is, and WHICH CAST, in this order:  S<song>-<code>-<what>-<CAST>.<ext>   The cast tag is ML (Maegan & Landon), AC (Andrew & Charlie), or SHARED (one file serves both casts). The code (M1, M7b, V2…) is the part the system reads — never change it; the rest is for humans.
- **Examples:** `S03-M1-pier-golden-hour-ML.jpg`, `S03-M1-pier-golden-hour-AC.jpg`, `S05-M12-dedication-for-cathy-SHARED.jpg`, `S07-V2-facetime-jamie-desk-ML.mp4`, `S07-V2-facetime-jamie-desk-AC.mp4`
- **Photos:** JPG (convert HEIC). Long side at least 1600 px. Keep each file under 8 MB so it travels through the Drive connector.
- **Video:** MP4 (H.264), 1920×1080 landscape. The video is larger than the Drive transfer limit: upload it to the GitHub repo (Add file → Upload files, into assets/) or give it to the show laptop — tell me which.
- **Audio:** M4A or MP3, mono is fine.
- **Where:** One Google Drive folder named  L5Y ASSETS , files flat inside it (no subfolders). Tell me when files land — I pull them and place every one by its code. A missing file keeps its placeholder, so partial uploads never break the show.
